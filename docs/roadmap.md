# Roadmap

This page lists what is planned for `tg` and is not in it yet. Read it before you build a workaround
for a missing feature: it may already be on the way. The order is approximate and can change. To
suggest something, open an [issue on GitHub](https://github.com/WireCatLabs/tg-cli/issues).

## What works today

Reading, sending, search, the local store, groups, people, bots, MCP and permissions: see
[using tg](usage.md) and [every command](commands.md). What each released version changed is in the
[changelog](../CHANGELOG.md).

## In progress

- **A checked copy of a chat's files.** Download a chat's files into a folder you choose, check later that
  every copy is still whole, and repeat it on a daily timer.

## Next

- **Several photos in one message.** Until then, see [what tg cannot send yet](usage.md#not-in-tg-yet).
- **Archive, pin and mute a chat, or mark it unread.** The WhatsApp and MAX tools already can.
- **A reply saved as the chat's draft.** Your agent writes it, you read it in Telegram and press send.

## Later

- **Your own notes on chats.** Private notes on a chat, like the ones
  [tgcli](https://github.com/kfastov/tgcli) keeps beside its tags. Private names and notes for people already work:
  [your own names and notes for people](people.md#your-own-names-and-notes-contacts-alias-contacts-notes).
- **Reactions by emoji in message rankings.** Beside the total, how many of each reaction a message got.
- **What `max` can do and `tg` cannot yet.** Privacy settings, call history, a chat's media, stickers,
  deleting or clearing a chat for yourself, a group photo, pressing a bot's buttons, starting a bot and
  opening its mini app.
- **Your location in a message.**
